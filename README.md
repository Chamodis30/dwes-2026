# Proyecto DWES 2026

## Descripción
Este es un proyecto de practica para la asignatura de Desarrollo Web en Entorno Servidor (DWES). El objetivo es aprender a estructurar un proyecto web, utilizar el control de versiones con Git y documentar correctamente un repositorio.

## Estructura del proyecto
La organizacion de las carpetas es la siguiente:
-**`public/`**: Archivos publicos accesibles desde el navegador (HTML, CSS, JS, imagenes).
-**`src/`**: Codigo fuente del servidor (logica de la aplicacion, PHP, etc.).
-**`docs/`**: Documentacion adicional del proyecto.
-**`README.md/`**: Este archivo, con la información principal del proyecto.
-**`.gitignore`**: Archivo para evitar subir dependencias y archivos sensibles.

## Tecnologias usadas
- PHP
- HTML5 / CSS3
- Git y GitHub
